A fair source license permits all uses of the code except in projects that directly commercially compete with the project that created that code. Four years after release, the license converts to an ordinary permissive FOSS license.

It protects open projects from some forms of exploitation, and so, it is named "fair". It's not the fairest imaginable thing, but it is fairer than immediately releasing as full foss. Heroic self-sacrifice is not fair. It, you know, results in heroes being sacrificed.
